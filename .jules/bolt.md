## 2026-09-10 - Zero-allocation TCP frame decoding with CollectionsMarshal.AsSpan
**Learning:** In .NET 8, byte-by-byte list accumulation and intermediate byte array allocations in stream buffer accumulators (like `TcpFrameParser`) introduce significant GC pressure under high socket message throughput. Utilizing `CollectionsMarshal.AsSpan(list)` with `ReadOnlySpan<byte>.IndexOf` and `Encoding.UTF8.GetString(spanSlice)` eliminates intermediate `byte[]` heap allocations and leverages SIMD hardware acceleration.
**Action:** When building high-throughput TCP socket frame accumulators in C#/.NET 8, avoid allocating intermediate byte arrays for string decoding; decode directly from `CollectionsMarshal.AsSpan` memory slices and bulk append via `List<T>.AddRange(ReadOnlySpan<T>)`.
